# iranian-pos

اجرای سرویس رسمی **PC-POS ویندوز** روی لینوکس با Wine و Docker.

این پروژه پروتکل شاپرک را از نو ننوشته؛ همان فایل نصب PSP را روی لینوکس راه
می‌اندازد.

| PSP | پوشه | بسته رسمی |
|-----|------|-----------|
| سامان (SEP) | `psp/sep` | SSP1126 SignalR |
| ایران کیش | `psp/iran-kish` | PCPOS WebDll |

فایل‌های `.exe` / `.dll` و PDF شرکت‌ها را در گیت نگذارید. آن‌ها را از بسته
رسمی بگیرید و داخل `psp/<name>/vendor/` کپی کنید (این پوشه ignore است).

مستند فنی PSP را عمومی نکنید مگر خود شرکت اجازه داده باشد.
